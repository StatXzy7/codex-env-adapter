# 使用指南

日常推荐到 GitHub Release 下载 **Codex环境适配启动器**：

https://github.com/StatXzy7/codex-env-adapter/releases/latest

社区共识：时区要和出口一致；也不要多 IP 来回切、不要多设备同时登录，否则仍可能降智。

## 前置条件

- 已安装 ChatGPT / Codex Windows 桌面端（商店应用 `OpenAI.Codex`）
- Clash 正在监听启动器里的代理地址（默认 `127.0.0.1:7890`）。不必打开系统代理，也不要设置用户级 `HTTP_PROXY`

## 每天怎么用

1. 打开 Clash，选好节点，确认 mixed 端口和启动器里的代理地址一致。
2. 打开 `CodexEnvAdapter.exe`，点 **刷新探测**。
3. 确认出口城市、节点时区，以及「应用代理」开关。
4. 点 **保存并启动 Codex**。
5. 不要从开始菜单再开一次 ChatGPT，也不要同时开网页版或手机 App。

终端里的 `codex` 和 `claude` 是否走代理，由「终端里输入 codex / claude 也使用」控制。改完后新开一个终端才生效。Firefox 会固定走同一 HTTP 代理，并关闭 HTTP/3 直连；改完需要重启 Firefox。Chrome / Edge 仍认 Clash 打开的系统代理。

## Windows 上启动 Codex CLI

桌面 exe 给 Codex 桌面进程注入时区。终端里的 `codex` 若已勾选应用代理，会在这个命令自己的进程里走代理；时区仍要在**同一个 PowerShell 窗口**里设置 `TZ`：

临时一行（只对当前窗口有效）：

```powershell
$env:TZ = "America/Los_Angeles"
codex
```

自动按当前出口探测并启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-CodexCli.ps1
```

后面可以跟 Codex 自己的参数，例如：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-CodexCli.ps1 -- --help
```

不要把 `TZ` 写进系统/用户环境变量。关掉这个终端后再开新窗口，需要重新跑一次脚本。

## macOS / Linux

不要安装 Windows exe。时区问题同样存在，但用脚本注入 `TZ` 即可，系统时区不用改。

```bash
chmod +x scripts/unix/launch-codex.sh
./scripts/unix/launch-codex.sh
./scripts/unix/launch-codex.sh --cli
```

macOS 也可双击 `scripts/macos/Launch-Codex.command`。说明见 `docs/平台说明.md`。

也可以继续用 PowerShell 脚本（在仓库根目录执行）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Show-CodexEnvironment.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-ChatGPT.ps1
```

## 换节点

出口变了，时区也要变。步骤：

1. 在 Clash 里切换节点
2. 再跑 `Show-CodexEnvironment.ps1`，看 IP 和 `Timezone` 是否已变
3. 再跑 `Launch-ChatGPT.ps1`（会结束旧进程）

常见对照：

| 出口大致位置 | 注入 TZ |
|--------------|---------|
| 加州 / 圣何塞 / 洛杉矶 | `America/Los_Angeles` |
| 纽约 | `America/New_York` |
| 伦敦 | `Europe/London` |
| 东京 | `Asia/Tokyo` |
| 新加坡 | `Asia/Singapore` |

不确定就用自动探测，不要手填。

## 指定时区

自动探测失败，或你确定要覆盖时：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-ChatGPT.ps1 -Timezone America/Los_Angeles
```

只检查、不启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-ChatGPT.ps1 -NoLaunch
```

ChatGPT 正在运行且你不想被结束：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Launch-ChatGPT.ps1 -KeepRunning
```

此时若进程仍在，脚本会报错退出，避免带错时区。

## 桌面快捷方式

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-DesktopShortcut.ps1
```

默认文件名：`Codex环境适配启动器.lnk`。

## 排错

| 现象 | 处理 |
|------|------|
| `未找到 OpenAI.Codex` | 先从 Microsoft Store 安装 ChatGPT / Codex |
| 探测超时 | 先开代理再探测；脚本会依次试 ipinfo / ipapi |
| 启动后仍像国内时区 | 确认不是开始菜单启动的；换节点后必须重启 ChatGPT |
| 出口 IP 还是国内 | Clash 没在启动器填写的端口上监听，或 ChatGPT 是从开始菜单打开的 |
| 双击 cmd 一闪而过 | 用 PowerShell 直接跑 `.ps1` 看完整报错 |
| 有未保存对话 | 启动器会结束已有 ChatGPT 进程，先保存再跑 |

JSON 探测输出：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Show-CodexEnvironment.ps1 -Json
```
