# 使用指南

## 前置条件

- 已安装 ChatGPT / Codex Windows 桌面端（商店应用 `OpenAI.Codex`）
- 已打开你的代理客户端，并让 GPT 流量走目标节点
- Windows PowerShell 5.1 或更高版本

## 每天怎么用

1. 打开代理，选好节点。
2. 运行探测：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Show-CodexEnvironment.ps1
```

确认出口城市不是国内，时区是节点时区。

3. 启动 ChatGPT：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Launch-ChatGPT.ps1
```

或双击 `scripts\Launch-ChatGPT.cmd`。

4. 不要从开始菜单再开一次 ChatGPT。

## 换节点

出口变了，时区也要变。步骤：

1. 在 Clash 里切换节点
2. 再跑 `Show-CodexEnvironment.ps1`，看 IP 和 `Timezone` 是否已变
3. 再跑 `Launch-ChatGPT.ps1`（会结束旧进程）

常见对照：

| 出口大致位置 | 注入 TZ |
|--------------|---------|
| 加州 / 圣何塞 / 洛杉矶 | `America/Los_Angeles` |
| 纽约 | `America/New_York` |
| 伦敦 | `Europe/London` |
| 东京 | `Asia/Tokyo` |
| 新加坡 | `Asia/Singapore` |

不确定就用自动探测，不要手填。

## 指定时区

自动探测失败，或你确定要覆盖时：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Launch-ChatGPT.ps1 -Timezone America/Los_Angeles
```

只检查、不启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Launch-ChatGPT.ps1 -NoLaunch
```

ChatGPT 正在运行且你不想被结束：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Launch-ChatGPT.ps1 -KeepRunning
```

此时若进程仍在，脚本会报错退出，避免带错时区。

## 桌面快捷方式

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Install-DesktopShortcut.ps1
```

默认文件名：`Codex-Timezone-Launcher.lnk`。

## 排错

| 现象 | 处理 |
|------|------|
| `未找到 OpenAI.Codex` | 先从 Microsoft Store 安装 ChatGPT / Codex |
| 探测超时 | 先开代理再探测；脚本会依次试 ipinfo / ipapi |
| 启动后仍像国内时区 | 确认不是开始菜单启动的；换节点后必须重启 ChatGPT |
| 出口 IP 还是国内 | 代理没生效，先修 Clash / 系统代理 |
| 双击 cmd 一闪而过 | 用 PowerShell 直接跑 `.ps1` 看完整报错 |
| 有未保存对话 | 启动器会结束已有 ChatGPT 进程，先保存再跑 |

JSON 探测输出：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\myprojects\codex-env-adapter\scripts\Show-CodexEnvironment.ps1 -Json
```
